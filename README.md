# MyGamesHub — система учёта настольных игр

## О проекте

**Заказчик:** компания MyGamesHub, организатор игрового клуба

**Проблема:** отсутствие автоматизированной системы учёта выдачи настольных игр. Текущий учёт ведётся в тетради, что приводит к ошибкам при бронировании, сложностям с поиском свободных игр и отсутствию истории выдачи.

## Функциональность

* **Каталог игр:** добавление, просмотр и управление информацией о настольных играх
* **Система бронирования:** бронирование игр посетителями с указанием имени
* **Поиск:** мгновенный поиск по названию и жанру
* **Статусы:** отслеживание статуса игры (в клубе/выдана)
* **Удаление:** безопасное удаление записей с подтверждением

## Технические требования

* **Язык программирования:** Python 3.11+
* **Графический интерфейс:** Tkinter
* **Структура данных:** список словарей в памяти
* **Сохранение:** опциональное сохранение в JSON

## Запуск программы

Для запуска приложения выполните следующие шаги:

1. Установите Python версии 3.11 или выше
2. Клонируйте репозиторий (рекомендуется исключить кирилицу в пути)
3. в редакторе кода выберите папку с программой
4. Установите зависимости (если они не были установлены заранее):
```bash
pip install -r requirements.txt
```
Запустите код через кнопку запуска в левой верхней части экрана или через команду в терминале
```bash
python3 app.py
```
