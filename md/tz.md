# Техническое задание: MyGamesHub

## 1. Архитектура и структура данных
Приложение реализовано в одном модуле `src/main.py`. Данные хранятся в глобальном списке словарей `games`:
```python
{
    "name": "Название игры (str)",
    "genre": "Жанр игры (str)",
    "players": "Количество игроков, например '2-4' (str)",
    "status": "'в клубе' или 'выдана' (str)"
}
```

## 2. Описание пользовательского интерфейса
Главное окно (`700x450`) состоит из четырёх логических блоков:
1. **Форма добавления (`ttk.Frame`):** поля ввода `name_entry`, `genre_entry`, `players_entry` и кнопка «Добавить».
2. **Строка поиска (`ttk.Entry`):** поле `search_entry` с привязкой к событию `<KeyRelease>` для мгновенной фильтрации.
3. **Таблица каталога (`ttk.Treeview`):** 4 колонки (`name`, `genre`, `players`, `status`) для отображения списка игр.
4. **Панель действий (`ttk.Frame`):** кнопки «Забронировать», «Вернуть» и «Удалить».

## 3. Обработка ошибок
* При попытке нажать «Забронировать», «Вернуть» или «Удалить» без выделенной строки в таблице выводится уведомление «Выберите игру в списке».
* При попытке забронировать игру со статусом `выдана` выводится предупреждение «Игра уже выдана».
