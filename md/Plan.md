# План проекта: MyGamesHub

## 1. График спринтов
Проект разбит на 3 спринта по 2 недели:

| Спринт | Основные задачи | Ожидаемый результат |
|---|---|---|
| **Спринт 1** (Недели 1–2) | Заполнение Устава, Требований и ТЗ. Проектирование интерфейса на Tkinter. Реализация формы ввода и добавления игр в таблицу. | Работающее окно, куда можно добавить игру (название, жанр, игроки) и увидеть её в списке. |
| **Спринт 2** (Недели 3–4) | Реализация мгновенного поиска по названию и жанру. Добавление логики смены статусов («в клубе» / «выдана») при бронировании и возврате. | Возможность найти нужную игру и изменить её статус с указанием имени игрока. |
| **Спринт 3** (Недели 5–6) | Добавление удаления записей с подтверждением. Проведение ручного тестирования (`tests/manual_checks.md`), оформление документации и релиза `v1.0`. | Готовый продукт, проверенный по всем сценариям и готовый к демонстрации заказчику. |

## 2. Инструменты управления
* **Контроль версий:** Git, ветка `main` и рабочие ветки `feature/...` слиянием через Pull Request.
* **Трекинг задач:** GitHub Issues и доска GitHub Projects.
