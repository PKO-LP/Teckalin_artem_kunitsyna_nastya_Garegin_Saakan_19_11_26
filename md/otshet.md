# Отчёты о статусе по итогам спринтов

## Отчёт по Спринту 1
* **Что сделано:** Оформлен Устав и Требования, создан репозиторий, реализовано главное окно Tkinter с полями ввода и добавлением записей в `Treeview`.
* **Что мешало:** Потребовалось время на настройку корректного отображения столбцов в таблице `ttk.Treeview`.
* **План на Спринт 2:** Реализовать поиск по списку и логику смены статусов при бронировании и возврате игр.

## Отчёт по Спринту 2
* **Что сделано:** Добавлена строка поиска с фильтрацией по клавише `<KeyRelease>`, реализованы функции `book_game()` и `return_game()` с проверкой текущего статуса.
* **Что мешало:** При бронировании нужно было предусмотреть отмену ввода имени игрока (если нажата кнопка «Отмена» или введена пустая строка).
* **План на Спринт 3:** Добавить удаление с подтверждением, провести ручное тестирование и подготовить релиз `v1.0`.

## Отчёт по Спринту 3 (Итоговый)
