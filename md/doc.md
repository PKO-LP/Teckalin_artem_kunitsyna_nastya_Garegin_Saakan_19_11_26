# Документация продукта: MyGamesHub (Руководство пользователя)

## 1. Назначение программы
Приложение **MyGamesHub** предназначено для администраторов клуба настольных игр. Оно позволяет вести список настольных игр, быстро искать свободные коробки и отмечать их выдачу посетителям.

## 2. Запуск приложения
1. Убедитесь, что на компьютере установлен Python версии 3.11 или выше.
2. Откройте терминал в корневой папке проекта и выполните команду:
   ```bash
   python src/main.py
   ```

## 3. Инструкция по работе
* **Добавление новой игры:** заполните поля *«Название»*, *«Жанр»* и *«Игроков»* (в формате числа или диапазона, например `2-5`) в верхней части окна и нажмите кнопку **«Добавить»**.
* **Поиск игры:** начните вводить название игры или её жанр в поле поиска над таблицей. Список обновится автоматически. Чтобы вернуть полный список, очистите строку поиска.
* **Выдача игры (бронирование):** кликните по нужной игре со статусом `в клубе` в таблице и нажмите кнопку **«Забронировать»**. В появившемся окне введите имя игрока и нажмите *ОК*. Статус изменится на `выдана`.
* **Возврат игры:** выберите в таблице игру со статусом `выдана` и нажмите **«Вернуть»**. Статус изменится обратно на `в клубе`.
* **Удаление игры:** выделите запись в таблице, нажмите **«Удалить»** и подтвердите действие в диалоговом окне.

## 4. Ограничения версии v1.0
Данные хранятся в оперативной памяти программы. После закрытия окна все внесённые изменения сбрасываются.
