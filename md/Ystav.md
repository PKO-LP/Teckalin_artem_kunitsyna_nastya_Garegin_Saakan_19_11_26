# Устав проекта: MyGamesHub

## 1. Общая информация
* **Название проекта:** Система учёта настольных игр «MyGamesHub».
* **Исполнитель:** Компания «MySoft» (разработчик: [Текалин Артем,Куницына Анастасия,Гарегин Саакян, 11ТЭС]).
* **Заказчик:** Игровой клуб «MyGamesHub».
* **Срок реализации:** 6 недель (3 спринта по 2 недели).

## 2. Обоснование и цель проекта
* **Проблема:** Администраторы клуба ведут учёт выдачи настольных игр в бумажной тетради. Это приводит к ошибкам при бронировании, долгому поиску свободных коробок и путанице с тем, какие игры сейчас на руках.
* **Цель:** Создать настольное приложение для быстрого поиска игр по каталогу, контроля их наличия и фиксации выдачи/возврата.

## 3. Границы проекта (Scope)
* **Входит в версию v1.0:** добавление игр в каталог, поиск по названию и жанру, бронирование на имя игрока, возврат игры в клуб, удаление записей с подтверждением.
* **Не входит в версию v1.0:** подключение баз данных (SQL), авторизация пользователей, сохранение истории в файлы (данные хранятся в оперативной памяти во время работы программы).

## 4. Критерии успеха
Приложение запускается на компьютере с Python 3.11+ без установки сторонних библиотек, выполняет все 5 заявленных сценариев без сбоев и сопровождается комплектом документации и ручных тестов.
