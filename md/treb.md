# Требования к системе MyGamesHub

## 1. Функциональные требования
1. **Добавление игры:** система должна позволять ввести название, жанр и количество игроков, после чего добавлять запись в список со статусом `в клубе`.
2. **Валидация ввода:**
   * Поля «Название» и «Жанр» обязательны для заполнения.
   * Поле «Игроков» должно содержать число или диапазон (например, `2-4`).
3. **Просмотр каталога:** отображение всех добавленных игр в виде таблицы со столбцами: *Название, Жанр, Игроков, Статус*.
4. **Поиск:** фильтрация списка в реальном времени при вводе текста по совпадению в названии или жанре (без учёта регистра).
5. **Бронирование и возврат:**
   * Забронировать можно только игру со статусом `в клубе` с вводом имени игрока во всплывающем окне. После этого статус меняется на `выдана`.
   * Вернуть можно только игру со статусом `выдана`, после чего статус снова становится `в клубе`.
6. **Удаление:** удаление выбранной в таблице игры после подтверждения пользователем в диалоговом окне.

## 2. Нефункциональные требования
* **Платформа и стек:** Python 3.11+ и стандартная библиотека графического интерфейса `tkinter` (`ttk`).
* **Хранение данных:** список словарей в оперативной памяти (`games = []`).
* **Понятность интерфейса:** все ошибки ввода и предупреждения сопровождаются информативными окнами `messagebox`.
